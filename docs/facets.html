Facet routing

Magnet words against the alternatives.

The current router embeds a sentence with e5-instruct and takes the bucket with the highest cosine to any of its magnet words. This is the same deterministic routing the dashboard uses.

The gold file and the production magnet bank are outside this repository. The gold is not published; the results below are aggregate metrics only.

Protocol

  • Gold: 1,075 hand-labelled sentences, 38 buckets, 6 categories; 482 dev / 593 fresh. Reported on the held-out fresh split.
  • Prediction: one bucket inside the sentence's known category.
  • Acceptable: a sentence can belong to more than one facet. The hand-labelled acceptable set lists every facet a labeller accepted for that sentence, so a prediction counts as correct when it matches any one of them. Most rows accept one facet; some accept two or three.
  • Metrics: top-1 coverage (whether the one predicted bucket is accepted), bucket-coverage macro, fit time and method time per sentence.
  • Shared cost: the e5 embedding pass is outside the per-method time; it is reported once below the table.

What the sweep shows

The current magnet router leads: 0.922 top-1 coverage and 0.937 bucket coverage on 593 fresh sentences. The strongest supervised alternative is linear SVM at 0.823 coverage; logistic regression reaches 0.801, the magnet centroid 0.809, and kNN 0.730. TF-IDF is 0.653. K-means, agglomerative clustering, NMF and LDA fall between 0.59 and 0.36; the random baseline is 0.194.

Fit time is 0.3–1.6 s for the trainable methods; the unsupervised routers have no fit. The nearest-magnet geometry is hard to beat here, and the remaining headroom is mostly vocabulary and bucket definition.

The production bucket set is tuned for a particular taxonomy. This repository ships an example set; the benchmark above uses the production bank locally and must not be read as a score for the example set.

Gold and production bank not released. See Decisions for why the magnets stay.
