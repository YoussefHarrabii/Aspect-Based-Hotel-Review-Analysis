Method

How a review becomes a facet.

The local pipeline reads one CSV, splits each review into sentences, labels every sentence, routes the result to a facet, and aggregates the mentions. The model is fitted offline; the service only loads saved weights.

Fit versus serve

The classifier and the sentiment probe are fitted outside the service. A build loads the saved classifier, the saved probe and the e5 encoder, processes the batch, and writes mentions. The server recomputes the aggregate from SQLite on GET /api/data and never fits anything.

The category model is one DeBERTa-v3-base seed. It has seven sigmoid outputs; Location is kept only because removing an output would change the label order, and it is excluded from aggregation and UI. General Experience is a vague facet, shown separately in the local dashboard and omitted from the showcase.

Stages

  1. Normalize reads the CSV into SQLite and removes exact and guarded near-duplicates.
  2. Segment slices long text, restores punctuation and splits on sentence boundaries.
  3. Classify runs the saved DeBERTa seed and thresholds each label.
  4. Probe embeds the sentence with e5-instruct and scores positive/negative; the neutral band is |p - 0.5| < 0.10.
  5. Facets compare the same e5 vector with each bucket's magnet words and take the highest cosine within the category and polarity.
  6. Aggregate counts reviews, mentions, categories, facets and quotes; build data writes the payload the page reads.
