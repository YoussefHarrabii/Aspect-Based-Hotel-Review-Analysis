Decisions

What this build does.

Short records of the choices that shape the output.

Scope

  • One property per batch, imported as a local CSV through the page.
  • The service reads the imported dataset and serves the overview.

Labels

  • Location is an Other catch-all. It stays in the checkpoint because removing an output would change the label order; it is excluded from F1, aggregation and UI.
  • General Experience is a catch-all facet. The local dashboard shows it in a separate block; the showcase omits it.
  • Six actionable categories are shown and scored. Location is the seventh model output.
  • In-room food and drink are Food & Drink.
  • View, quietness and noise are Room & Property.
  • Off-property people and operators are dropped from Staff & Service.

Model

  • One seed ships. The build uses cat_v5c_s2 as a single checkpoint. Category-macro F1 is 0.890 on the held-out gold; the measured three-seed spread is 0.025.
  • Sentiment is an e5-instruct embedding plus logistic regression. Scores inside |p - 0.5| < 0.10 become neutral.
  • Per-label thresholds are tuned on validation and applied to each sigmoid independently.
  • Facet routing stays deterministic. The sentence is embedded once and compared with each bucket's magnet words; the highest cosine wins within the category and polarity.

Facet benchmark

On the hand-labelled gold, the current magnet router leads the broad sweep at 0.922 top-1 coverage and 0.937 bucket coverage on 593 held-out sentences. Linear SVM reaches 0.823 coverage, logistic regression 0.801, the magnet centroid 0.809 and kNN 0.730. Clustering and topic models are below 0.59. The full table is on Facets.

The nearest-magnet geometry is hard to beat; the remaining headroom is mostly vocabulary and bucket definition.

Data

  • Exact duplicates are removed; near-duplicates are removed at a high token-overlap guard. The dataset lives under data/, which git ignores and the first import creates.
  • A duplicate review_id, a non-ISO date or a rating outside 1–5 rejects the import before the current dataset is cleared.

Gold labels and the production magnet bank are not released.
