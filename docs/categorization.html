Categorization

Three seeds were measured. One ships.

Production runs a three-seed ensemble with the rule stack. The release ships one checkpoint: it is the best single seed, and three fp16 files would triple the download.

Protocol

  • Gold: one held-out Tunisian property, 1,033 snippet examples, six actionable categories, Location excluded from the score.
  • Scoring: a neutral mention counts as category-present; each single-seed row uses that checkpoint's own per-label thresholds and no rules.
  • Ensemble: the production row averages the three sigmoid outputs, thresholds with the ensemble file and applies the rule stack, so it is not a like-for-like single model.
